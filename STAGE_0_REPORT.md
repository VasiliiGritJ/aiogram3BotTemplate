# Отчёт по этапу 0

## Подготовленное окружение

- Рабочая ветка: `develop/fitness-coach-foundation`.
- Проверенная версия: Python 3.12.10 (64-bit).
- Локальное окружение: `.venv` в корне проекта.
- Зависимости установлены без изменения версий из `storage/requirements.txt`.
- `storage/.env`, `.venv/`, `__pycache__/` и скомпилированные Python-файлы игнорируются Git.
- Безопасный шаблон конфигурации находится в `storage/.env.example`.

## Локальный запуск на Windows

Из корня проекта:

```powershell
Copy-Item storage/.env.example storage/.env
```

Откройте `storage/.env` и замените фиктивное значение на реальный `BOT_TOKEN`, полученный у BotFather. Не публикуйте токен в чате или Git.

```powershell
.\.venv\Scripts\Activate.ps1
python bot.py
```

YooKassa и её секреты для запуска не требуются.

## Выполненные проверки

- `python -m pip check`: конфликтов установленных пакетов нет.
- `python -m compileall`: исходный код компилируется.
- Импорт `bot.py` с локальным фиктивным токеном: успешен, сетевое подключение не выполнялось.
- В диспетчере зарегистрированы обработчики сообщений и callback-кнопок, включая `/start` и профиль.
- На временной копии `db.db` проверено создание и последующее чтение пользователя через `User.get_or_create()` и `User.get()`.
- До реального запуска исходный `db.db` не изменялся; во время ручной проверки `/start` бот штатно сохранил одну пользовательскую запись в рабочую SQLite-базу.

При импорте появляется предупреждение из связки зафиксированных `aiogram 3.24.0` и `pydantic 2.7.4` о защищённом пространстве имён. Оно не блокирует запуск; версии намеренно не менялись в рамках этапа 0.

## Результат проверки с реальным токеном

Локальный `storage/.env` найден, игнорируется Git и успешно загружается приложением. Формат токена принимается `aiogram`, сам токен нигде не выводился.

После восстановления сетевого доступа безопасный вызов `getMe` успешно подтвердил соединение с Telegram API и валидность локального токена. Затем бот был запущен командой `python bot.py` из корня проекта; polling стартовал успешно.

Владелец вручную подтвердил:

- команда `/start` работает;
- бот отвечает пользователю;
- кнопка «Профиль» открывает и корректно отображает профиль.

После проверки фоновый polling-процесс остановлен. Дополнительная проверка подтвердила, что запущенный для этапа 0 процесс `bot.py` больше не работает.

## Итог

Критерии этапа 0 выполнены: проект воспроизводимо запускается на Windows с Python 3.12, зависимости установлены, секреты игнорируются Git, Telegram API доступен с валидным локальным токеном, `/start` и профиль работают, пользователь успешно сохранён и читается из SQLite, а YooKassa для запуска не требуется.
